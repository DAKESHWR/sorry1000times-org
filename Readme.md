# Apology Message Generator
 
A free, privacy-friendly web tool that helps you write sincere, well-worded apology messages in seconds. Choose the situation, tone, and length, and get a personalized message you can copy, download, or send straight to WhatsApp.
 
**Live demo:** [sorry1000times-org.vercel.app](https://sorry1000times-org.vercel.app/)

## Features
 
- **Personalized messages:** add the recipient's name and the message adapts to it.
- **Six situations:** delayed reply, forgotten birthday or anniversary, careless mistake, heated argument, missed call, or a general heartfelt apology.
- **Six emotional tones:** sincere, playful, poetic, humorous, romantic, and professional.
- **Flexible length:** target 50, 100, 500, or 1,000 words.
- **Emoji control:** subtle, expressive, emojis only, or clean text with no emojis.
- **Severity slider:** match the message to how serious the mistake was.
- **Surprise Me:** generate a message with randomized settings.
- **Preset templates:** filter by Heartfelt, Romantic, Playful, Quick Texts, and Professional, then load any template into the generator.
- **One-click actions:** copy all, save as `.txt`, share on WhatsApp, or read the message aloud with speech synthesis.
- **Live counters:** word and character counts update as you edit.
- **Fully editable output:** fine-tune the generated text before sending.
- **Responsive design:** works on phones, tablets, and desktops.

## How It Works
 
1. Enter the **recipient's name**.
2. Pick the **situation** and **emotional tone**.
3. Choose a **target length** and **emoji style**.
4. Set the **blunder severity** with the slider.
5. Click **Generate Message** (or **Surprise Me**).
6. Edit the text if you like, then **copy, save, speak, or share** it.

## Tips for Writing a Good Apology
 
A meaningful apology is more than saying "I'm sorry." These principles guide the templates in this project:
 
1. **Acknowledge what happened.** Name the specific mistake instead of being vague.
2. **Take full responsibility.** Avoid conditional phrasing such as "I'm sorry if you felt hurt."
3. **Express genuine regret.** Show that you understand the impact on the other person.
4. **Offer concrete amends.** Explain what you will do differently so it doesn't happen again.
5. **Give them space.** Forgiveness takes time, so don't pressure the other person to respond.
**Short vs. long:** a crisp 50-word note suits minor slip-ups like a late reply, while a longer letter suits serious breaches of trust or heated arguments.

## Playful Apologies and Repeat Text
 
Between close friends and partners, humor can break the tension after a small mistake. A popular lighthearted trick is sending a repeated "sorry" message. If you want to try that, you can use a [sorry 100 times](https://sorry100times.org/) text repeater to generate the message and paste it into your chat.
 
Keep in mind that repetition can carry emotion, but it cannot carry accountability. For anything serious, follow it with a sincere, specific apology, which is exactly what the generator in this project is built for.

## Privacy
 
All message generation and editing happens **100% in your browser**. Recipient names, notes, and generated messages are never uploaded, recorded, or stored on a server.

## Getting Started
 
### Run locally
 
```bash
# Clone the repository
git clone https://github.com/DAKESHWR/sorry1000times-org
 
# Move into the project folder
cd your-repo-name
 
# Open index.html in your browser
```
 
If you prefer a local server:
 
```bash
# Using Python
python3 -m http.server 8000
 
# Or using Node.js
npx serve .
```
 
Then visit `http://localhost:8000`.
 
### Deploy
 
Because the project is a static site, you can host it for free on GitHub Pages, Netlify, Vercel, or Cloudflare Pages. For GitHub Pages: go to **Settings → Pages**, select your branch, and save.
